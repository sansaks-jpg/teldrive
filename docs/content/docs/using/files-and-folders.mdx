title: Files and folders

The **Files** page supports list and grid views, multi-selection, right-click context menus, uploads, copy/cut/paste, drag-and-drop move (including multi-item drag), rename, sharing, downloads (including folder ZIP downloads), and Trash.

## Navigation

The Drive UI includes dedicated views for **Files** (`/files`), **Photos** (`/photos`), **Storage** (`/storage` — quota usage and largest-file breakdown), **Shared** (`/shared`), **Shared with me** (`/shared-with-me`), **Trash** (`/trash`), and **Tasks** (`/tasks`). In-tab filters let you narrow results by type, date, or size.

## Selection

Single-click selects (with `Shift`/`Ctrl`/`Cmd` range and toggle selection). Open folders explicitly or by double-clicking so selection does not trigger navigation.

Bulk actions support copy, move, download, and trash. Rename and share are single-item actions.

## Copy, move, rename

Use the selection action bar or clipboard-style copy/cut/paste controls. Renaming changes catalog metadata; file payloads are not re-uploaded.

## Download

Download selected files or copy authenticated download links. Large files support HTTP range requests for seeking/streaming.

## Trash

Delete moves items to **Trash**. From Trash, restore or permanently purge them.

Purge is destructive.
